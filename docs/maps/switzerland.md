## Rules

| Rule | Switzerland |
|---|---|
| Players | 2-3 |
| Trains each | 40 |
| Opening hand | 4 cards |
| Opening tickets | 5, keep 2+ |
| Ticket draw | 3, keep 1+ |
| Unkept opening tickets | leave the game |
| Returned tickets | leave the game |
| Double routes | one side only with 2 players, except routes marked "parallel route open" |
| Locomotives | only on tunnels |
| Face-up locomotive | ordinary draw (can be one of two cards) |
| Face-up row redealt at | 3 locomotives |
| Tunnels | 3 cards revealed |
| Longest path bonus | 10 |
| Most tickets bonus | none |
| Rules engine version | 0 |

**Country tickets.** France, Austria, Germany and Italy are single places on the board, each reached by several
border routes. Tickets 34-45 list several destinations with a value for each. A completed ticket scores the best
destination its owner has connected; an uncompleted one loses its lowest value.
